# 員工管理｜免核對版（2026-11-17）

- 移除員工列表上的「舊資料待核對」提示與「核對資料」按鈕。
- 移除員工核對視窗及額外的核對資料 API 呼叫。
- 出勤／薪資共用名單沿用既有「姓名＋電話」歸組，對每組採固定的既有員工 ID；不再要求人工核對，也不依賴 employee_identity_reviews 資料表。
- 保留舊員工資料、ID、報價、派工、績效、出勤及薪資紀錄，**沒有執行資料庫合併或刪除**。
- 一個人可以編輯多個職位；登入權限不因職位改變。

## 請注意

這是移除核對介面的安全版，不代表歷史重複員工 ID 已在資料庫層真正合併。若同一人的歷史出勤或薪資分別儲存在不同 ID，統計仍需後續校正，請先以測試分支驗證再正式部署。

其他出勤薪資表仍需按既有 migration 建立；此次僅移除「員工核對」額外依賴。
