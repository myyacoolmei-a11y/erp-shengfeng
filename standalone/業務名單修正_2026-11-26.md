# 業務名單修正
原始碼的報價單、客戶管理與客戶詳細頁原先以 position === "業務" 篩選，會排除多職位字串。已改共用職位解析與有效員工選單（在職、配合；排除離職），使用原始員工 ID，不寫死姓名。派工技師與配送選單也使用共用選單；員工 API 的 position 查詢支援多職位。相同姓名及非空電話才去重，優先在職紀錄。既有報價及客戶編輯保留原負責人顯示。
未修改資料庫結構、薪資計算、登入權限或業績歸屬。薪資及維修案件使用不同的資料來源，未改動其身分關聯。
測試：node --experimental-strip-types tests/employeePositions.test.mjs（Node 22）。已通過模擬資料測試；完整 npm build 需要安裝依賴，本環境離線快取不足，未完成。未連接正式資料庫。部署後請測試新增與編輯報價、儲存及重新載入。
